LAN Device Security Self-Check

Modular exploit-verification portal for devices you own. Each check is a drop-in module — no server rebuilds, no restart: drop a folder in portal/modules/ and it appears here.

Authorization & scope. Only run these checks on devices you own or are explicitly authorized to test. Every module is proof-level only (pointer leak / primitives) and never escalates to code execution. Open a module on a device, run it, watch the operator dashboard. Ctrl-C the launcher and everything is offline.
